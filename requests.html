Tối ưu độ phức tạp thuật toán Dynamic Programming trên cây (Tree DP)

Em nộp bài trên Codeforces bị lỗi Time Limit Exceeded ở testcase 45. Em muốn mentor review thuật toán và chỉ ra điểm nghẽn bộ nhớ khi đệ quy sâu với N = 200,000 đỉnh.

solution_tree_dp.cpp C++20 
int solve(int u, int p) {
    dp[u][0] = 0; dp[u][1] = val[u];
    for (int v : adj[u]) {
        if (v == p) continue;
        solve(v, u);
        dp[u][0] += max(dp[v][0], dp[v][1]);
        dp[u][1] += dp[v][0];
    }
    return max(dp[u][0], dp[u][1]);
}
